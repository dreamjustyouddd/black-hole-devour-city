# 黑洞吞噬城市 (Black Hole Devour City)

一款基于 Canvas 的浏览器休闲游戏。控制黑洞在 90 秒内吞噬城市中的各种物品，不断壮大自己，挑战最高分。

## 玩法

使用 **WASD** 或 **方向键** 控制黑洞移动。黑洞会自动吸附靠近的物品，当物品足够小时即可吞噬。

- **吞噬物品** → 获得分数，黑洞变大
- **黑洞越大** → 移动越慢，但能吞噬更大的目标
- **90 秒内** → 尽可能获得高分

### 胜利条件

吞噬全部 **12 种**不同类型的物品后，若场上已无剩余物品，即刻获胜。

## 物品一览

| 类别 | 物品 | 基础分数 | 所需黑洞半径 |
|------|------|---------|-------------|
| 小型 | 行人、垃圾、灌木、长椅 | 3~5 | 无要求 |
| 中型 | 汽车、路灯、树木、栅栏、限时宝石 | 8~150 | 0~15 |
| 大型 | 房屋、高楼、大厦、桥梁 | 50~350 | 28~70 |
| 分裂 | 减分建筑 | 0（触发分裂） | 80 |

## 游戏机制

### 时间压力

- **最后 30 秒**：倒计时加速至 1.5 倍，HUD 变红警告
- **限时宝石**：10 秒后开始每 15 秒出现一颗紫色水晶，5 秒内未吞噬则消失并扣除一半分数
- **边缘建筑消失**：游戏过半后，地图边缘的建筑会每隔 4 秒随机消失一个

### 分裂建筑（原减分建筑）

深红色巨型建筑，分布在地图边缘，带有明显的脉冲动画和红色光晕：

- 自带**斥力场**，靠近时黑洞会被推开
- 被吞噬后**不扣分、不惩罚**，改为触发**黑洞分裂**
- 分裂为两个独立黑洞，大小、速度、引力均与源黑洞相同
- 两个黑洞**同步受 WASD / 方向键控制**，一起移动
- 每个黑洞都能独立吞噬物品、增长，**共用分数与时间**
- 最多可分裂为 4 个黑洞（防止指数爆炸）
- 每局最多生成 2 个分裂建筑

### 黑洞分裂机制

触碰减分建筑后，黑洞分裂为两个：

- 两个黑洞继承源黑洞的**全部属性**（半径、速度）
- 分裂时两个黑洞会向两侧弹开，带有初始速度
- 每个黑洞都有自己的引力场，独立吸附物品
- 相机自动跟随所有黑洞的**质心**
- HUD 显示最大黑洞的半径

### 彩虹模式

分数达到 **5000** 时激活：

- 黑洞外光晕变为动态彩虹渐变，发光范围扩大
- 光环旋转速度翻倍，新增多层嵌套彩色光环
- 吞噬粒子特效同步变为彩虹色
- 背景变暗并出现星空效果，突出黑洞压迫感

分数低于 5000 时自动恢复为普通紫色光效。

## 技术栈

- **纯前端**：HTML5 Canvas + 原生 JavaScript + CSS3
- **零依赖**：无需任何框架或构建工具
- **单页应用**：`index.html` + `style.css` + `game.js`

## 运行方式

直接在浏览器中打开 `index.html` 即可游玩，推荐使用 Chrome / Edge / Firefox 等现代浏览器。
